# ShipWave Print Agent

Installers for the ShipWave Print Agent, the desktop app that prints your
ShipWave shipping labels automatically in the background.

- **Windows 10/11:** [Download for Windows](https://github.com/levyelectric/shipwave-print-agent-releases/releases/latest/download/ShipWave-Print-Agent-Setup-windows.exe)
- **macOS 12+ (Apple Silicon and Intel):** [Download for Mac](https://github.com/levyelectric/shipwave-print-agent-releases/releases/latest/download/ShipWave-Print-Agent-mac.dmg)

Setup: install the app, then follow **Settings → Printing** in your ShipWave
account at https://shipwave.app/admin/settings/printing to generate your agent
token, paste it into the agent, and choose your label printer.

Installed agents update themselves from this page's releases.

Questions: support@shipwave.app
